# GLUCOLAB — local brand-reference SVG graphics

**Fix:** All 12 non-Libre device cards now display visual SVG graphics directly in HTML. The cards no longer try to fetch brand images from blocked third-party hosts and never replace them with text-only placeholders. Four Libre icons retain the existing yellow SVG butterfly.

**Attribution/accuracy:** The included SVGs are locally reconstructed brand-reference graphics using publicly visible manufacturer branding; they are **not** original downloaded master logo files from the manufacturers, and small details or fonts may differ. Dexcom G6/G7 app symbol shapes were based on official Dexcom compatibility imagery. Other marks were modelled on manufacturer-published brand examples. This is a non-commercial, local GLUCOLAB UI and not an authorized manufacturer endorsement.
